# 👨‍💻 My Portfolio Website

A personal portfolio website built with **React** and **TypeScript** to showcase my projects, skills, and resume. It features a modern, responsive design and allows recruiters to easily view and download my resume.

🔗 **Live Demo:** (https://anshu-annela-portfolio-website-vwlo.vercel.app/)

## 🚀 Tech Stack

* **Frontend Framework:** React
* **Language:** JavaScript
* **Build Tool:** Vite
* **Styling:** Tailwind CSS (or CSS Modules if applicable)
* **Deployment:** Vercel

## ✨ Features

* **Responsive Design:** Looks great on mobile, tablet, and desktop.
* **Resume Integration:** Users can view or download my resume directly (PDF format).
* **Project Showcase:** Displays key projects with links to GitHub repos and live demos.
* **Interactive UI:** Smooth hover effects and modern component architecture.

## 🛠️ Installation & Setup

Follow these steps to run the project locally on your machine.

**Prerequisites:**
* Node.js (v18 or higher recommended)
* npm (or yarn)

**1. Clone the repository**
```bash
git clone (https://github.com/anshuannela85/Anshu-Annela_Portfolio_website)
cd Portfolio-Website

```

**2. Install dependencies**

```bash
npm install

```

**3. Run the development server**

```bash
npm run dev

```

Open your browser and visit `http://localhost:5173` to see the site.

## 📦 Building for Production

To create an optimized build for deployment:

```bash
npm run build

```

This generates a `dist` folder containing the production-ready files.

## 📂 Project Structure

```text
├── public/          # Static assets (Resume PDF, Favicon, Images)
├── src/
│   ├── assets/      # Source images and icons
│   ├── components/  # Reusable React components (Header, Footer, etc.)
│   ├── styles/      # CSS or Tailwind configuration
│   ├── App.tsx      # Main application component
│   └── main.tsx     # Entry point
├── index.html       # Main HTML file
├── package.json     # Project dependencies and scripts
├── tsconfig.json    # TypeScript configuration
└── vite.config.ts   # Vite configuration

```

## 📝 Customization Notes

* **Resume:** The resume file is located in the `src/` folder as `resume.pdf` to ensure direct browser access.
* **Images:** Icons for "View" and "Download" are stored in `src/assets/`.
